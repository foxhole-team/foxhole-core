# FoxHole Core 1.0.1 — English

- Emergency kill switch now blocks new flows and revokes the prior epoch even when an expired categorized DNS feed rejects the normal reload. Feed signatures and freshness remain strict.
- Active DNS queries stop on policy, UID/package or runtime revocation, including fallback attempts and final TUN replies. Cancelled pooled UDP/TCP sessions are discarded.
- Only a typed revision CAS failure reports a revision conflict; existing refusal ABI values 1–9 are unchanged.
- Partial Clash and SIP008 imports retain valid nodes and report safe indexed refusals. Strict imports, duplicate-key rejection and global bounds remain enforced.
- CLI bootstrap keeps addresses already received when the shared five-second budget expires during a later query.

Validation: 51 focused Mac host tests passed for the affected parser/DNS/policy and deterministic-clock cases. Third-party versions and checksums are unchanged. This is not qualification of new JNI/Linux binaries, physical devices or independent peers; see docs/interop.md for exact artifact status. Native acceptance is bound separately to the owner-approved LAB artifact and provenance accompanying this release.
