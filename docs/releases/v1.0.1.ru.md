# FoxHole Core 1.0.1 — Русский

- Аварийный kill switch блокирует новые flows и отзывает прежнее поколение даже при отказе обычного reload из-за истёкшего categorized DNS feed. Проверки подписи и свежести сохранены.
- Активные DNS-запросы прекращаются при отзыве политики, UID/пакета или runtime, включая резервные upstream и финальный ответ в TUN. Отменённые UDP/TCP-сессии удаляются из пула.
- Конфликт ревизии возвращается только для типизированной ошибки CAS; существующие ABI-коды отказов 1–9 не изменены.
- Частичный импорт Clash и SIP008 сохраняет корректные узлы и выдаёт безопасные отказы с индексами. Строгий импорт, запрет повторяющихся ключей и общие лимиты сохранены.
- CLI bootstrap сохраняет уже полученные адреса, если общий пятисекундный бюджет истекает во время следующего запроса.

Проверка: пройден 51 целевой тест на Mac для затронутых parser/DNS/policy-сценариев и детерминированных часов. Версии и checksums сторонних зависимостей не изменены. Это не приёмка новых JNI/Linux binaries, физических устройств или независимых пиров; точный статус артефактов указан в docs/interop.md. Нативная приёмка отдельно привязывается к одобренному владельцем LAB-артефакту и provenance этого релиза.
